## Реализация пользовательского интерфейса

Пользовательский интерфейс приложения реализован с использованием фреймворка React Native, что позволяет создавать кроссплатформенные мобильные приложения с единым кодом для iOS и Android.

---

## 1. Архитектура интерфейса

Интерфейс построен на основе компонентного подхода. Каждый экран представляет собой отдельный компонент, что обеспечивает переиспользуемость и упрощает поддержку кода.

Структура экранов:
- LoginScreen
- ChatListScreen
- ChatScreen
- NewChatScreen
- SettingsScreen
- SecurityScreen

Для навигации используется библиотека React Navigation.

---

## 2. Навигация

В приложении реализованы два типа навигации:

### 2.1 Tab Navigation

Основная навигация реализована через нижнюю панель вкладок:

- Chats
- New Chat
- Settings

Используется createBottomTabNavigator.

---

### 2.2 Stack Navigation

Для переходов между экранами используется стековая навигация:

- ChatList → ChatScreen
- ChatScreen → SecurityScreen
- NewChat → ChatScreen

Используется createNativeStackNavigator.

---

## 3. Реализация экранов

---

### 3.1 ChatListScreen

Основной экран реализован с использованием FlatList для отображения списка диалогов.

Основные элементы:
- строка поиска (TextInput);
- список диалогов (FlatList);
- элементы списка (TouchableOpacity).

Особенности:
- динамическая фильтрация списка;
- отображение непрочитанных сообщений;
- индикаторы безопасности.

---

### 3.2 ChatScreen

Экран диалога реализован с разделением на три части:

1. Header
2. MessageList
3. InputArea

#### MessageList
Используется FlatList с оптимизацией производительности.

#### Сообщения:
- отображаются через кастомный компонент MessageBubble;
- различаются по стороне (входящие/исходящие).

#### InputArea:
- TextInput для ввода текста;
- кнопка отправки (Pressable).

---

### 3.3 NewChatScreen

Экран создания диалога включает:
- строку поиска;
- список пользователей.

Используется FlatList для отображения результатов поиска.

При выборе пользователя:
- инициируется создание защищённой сессии;
- выполняется переход к ChatScreen.

---

### 3.4 SecurityScreen

Экран безопасности реализован с использованием простых компонентов:

- Text — для отображения информации;
- View — для группировки блоков;
- Pressable — для действий (Verify, Copy).

Отображает:
- статус шифрования;
- fingerprint;
- информацию об алгоритмах.

---

## 4. Основные компоненты

---

### 4.1 MessageBubble

Отвечает за отображение сообщений.

Функции:
- различие входящих и исходящих сообщений;
- отображение статуса доставки;
- поддержка жеста "reply".

---

### 4.2 ChatItem

Элемент списка диалогов.

Содержит:
- аватар;
- имя;
- последнее сообщение;
- время;
- индикатор непрочитанного.

---

### 4.3 SearchBar

Переиспользуемый компонент поиска.

Функции:
- ввод текста;
- debounce (опционально);
- фильтрация данных.

---

## 5. Работа с жестами

Для реализации жестов используется библиотека:

react-native-gesture-handler

Реализованные жесты:
- свайп по элементу списка (удаление, закрепление);
- свайп по сообщению (reply);
- свайп назад (навигация).

---

## 6. Стилизация

Стили реализованы с использованием StyleSheet.

Особенности:
- тёмная тема по умолчанию;
- единая цветовая схема;
- использование flexbox для адаптивной верстки.

Пример:

const styles = StyleSheet.create({
  container: {
    flex: 1,
    backgroundColor: '#0F172A'
  }
});

---

## 7. Оптимизация производительности

Для повышения производительности используются:

- FlatList (вместо ScrollView);
- keyExtractor для списков;
- memo (React.memo) для компонентов;
- lazy loading экранов.

---

## 8. Интеграция с криптографией

UI взаимодействует с криптографическим слоем следующим образом:

- при создании диалога вызывается функция установления сессии (X3DH);
- сообщения перед отправкой шифруются;
- в интерфейсе отображается статус защищённости;
- пользователь может проверить ключи через SecurityScreen.

---

## 9. Итоги реализации

Использование React Native позволило:
- создать кроссплатформенное приложение;
- реализовать современный интерфейс;
- интегрировать сложную криптографическую логику в простой пользовательский опыт.

Компонентный подход и разделение логики обеспечивают масштабируемость и удобство дальнейшего развития приложения.
