## Диаграмма пользовательских сценариев

Для анализа взаимодействия пользователя с системой была разработана диаграмма пользовательских сценариев (User Flow), отражающая основные пути использования приложения.

Начальной точкой является экран авторизации, после которого пользователь попадает на главный экран — список диалогов. Данный экран выступает центральным узлом навигации, предоставляя доступ к основным функциям системы.

Пользователь может:
- открыть существующий диалог;
- воспользоваться поиском для быстрого доступа к диалогу;
- создать новый диалог через экран поиска пользователей.

При создании нового диалога автоматически инициируется процесс установления защищённой сессии, после чего пользователь переходит на экран общения.

Экран диалога поддерживает несколько сценариев:
- отправка сообщений;
- взаимодействие с сообщениями (жесты);
- переход к дополнительным функциям через меню.

Через контекстное меню пользователь может перейти на экран безопасности, где доступны функции проверки подлинности собеседника и просмотра криптографических параметров.

Таким образом, пользовательский поток организован вокруг основного сценария обмена сообщениями, при этом функции безопасности интегрированы в интерфейс без усложнения взаимодействия.
